Archive - scripts from the preprint version

These scripts were part of the preprint version of this repository (2025) and are not used for the
figures of the revised manuscript. They are kept here, unchanged, with their readme files and
example data.

  script_QY_plot.R     Quantum yield (QY) time series across several assays
                       (readme_script_QY_plot.txt, example_data/example_script_QY.txt)
  script_PSrates.Rmd   R Markdown report for photosynthetic rates
                       (readme_script_PSrates.txt, example_data/example_script_PSrates.xlsx).
                       Replaced by anova_bar/PSrates_anova.R for Figure S3.
